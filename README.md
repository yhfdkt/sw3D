# 基因表达实验室｜从基因到蛋白质

面向高中生的中文互动课。从真核细胞剖面进入，按七个场景观察转录、RNA 加工与出核、翻译和多肽折叠。**现已集成 33 个 3D 生物模型，可在 2D 动画讲解与 3D 立体观察之间自由切换。**

## 离线启动

双击 `index.html`，用 Chrome 或 Edge 打开。保留本目录中的全部文件及目录结构。页面采用本地 HTML、CSS、JavaScript，打开后即可离线运行。

课堂投屏可用页面右上角的「全屏」和「大字」。从左侧进入任意场景，在底部播放、拖动或单步观察。遇到橙色时间轴刻度，完成右侧题目或点击对应结构后，动画继续。重播会重新开启本步任务。

## 3D 模型功能

### 切换方式

- 点击页头右侧 **「3D 模型」** 按钮，在 2D 动画和 3D 模型之间切换。
- 也可按键盘 **M 键** 快速切换。
- 在 3D 模式下，左侧导航栏底部出现 **「3D 模型库」** 入口，可浏览全部 33 个模型。

### 3D 操作

| 操作 | 方式 |
|---|---|
| 旋转 | 鼠标左键拖拽 / 单指划动 |
| 缩放 | 滚轮 / 双指捏合 |
| 平移 | 鼠标右键拖拽 / 双指移动 |
| 预设视角 | 右上角工具栏：默认 / 正面 / 顶面 / 侧面 |
| 自动旋转 | 工具栏 ↻ 按钮 |
| 复位视角 | 工具栏 ⌂ 按钮 |
| 调节透明度 | 右下角透明度滑块 |
| 切换模型 | 右侧面板下拉选择器 |

### 模型与课程关联

每个教学场景默认加载最相关的 3D 模型。你也可以通过右侧面板的「关联 3D 模型」下拉菜单切换浏览其他相关模型，或从模型库中任意选择。

| 场景 | 默认 3D 模型 |
|---|---|
| 进入细胞 | 动物细胞剖面模型 |
| DNA 转录 | DNA 双螺旋结构模型 |
| RNA 加工 | 细胞核剖面模型 |
| mRNA 出核 | 细胞核剖面模型 |
| 翻译延伸 | 核糖体模型 |
| 翻译终止 | 核糖体模型 |
| 多肽折叠 | 蛋白质三维结构模型 |

## 源文件

- `course.js` — 教学文案、关键帧、反馈、示例序列，以及 3D 模型映射数据。
- `molecules.js` — SVG 分子图和各场景的 2D 运动。
- `player.js` — 管理播放、答题、缩放、投屏控件，以及 2D/3D 模式切换。
- `model3d.js` — **新增**：3D 生物模型查看器（基于 Three.js）。管理 WebGL 渲染、GLB 模型加载、OrbitControls 交互、CSS2D 标注和模型库面板。
- `index.html`、`style.css` 和 `mark.svg` — 页面结构与视觉样式。
- `lib/` — **新增**：Three.js 库及插件（three.module.min.js、GLTFLoader.js、OrbitControls.js、CSS2DRenderer.js、BufferGeometryUtils.js）。
- `models/` — **新增**：33 个 GLB 格式的 3D 生物模型文件（约 1.1 GB）。

## 技术说明

- 3D 渲染使用 **Three.js r170**（ES module），通过 `<script type="importmap">` 映射本地路径。
- 模型加载使用 GLTFLoader，支持异步加载与缓存。
- 结构标注通过 CSS2DRenderer 在 3D 场景中叠加 HTML 标签。
- WebGL 2.0 为必需条件；若不支持，页面将给出提示，2D 功能不受影响。
- 所有依赖均为本地文件，无需网络连接。

## 教学说明

转录与翻译共用一段编码示例。RNA 加工使用独立的外显子与内含子结构示意，折叠场景换用更长的多肽模型。分子大小、时间和距离均为教学示意。3D 模型供立体观察，与 2D 动画互补使用。
